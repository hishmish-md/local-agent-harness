Paste the [single setup prompt](FRIEND-HERMES.md) into your existing Hermes chat. It checks the repository, prepares or reuses two worktrees, and gives you one report for Astra. Prefer manual setup? Use the [two ticket briefs and Git steps](FRIEND-PROMPTS.md) **instead**.

| Peer | First ticket / write scope | Review |
|---|---|---|

Sol and friend Neon are peers. Neither assigns work to the other. Owner Astra acknowledges claims and integrates reviewed work. Sol’s later qualification ticket is **not** a third setup workspace. See [coordination](../COORDINATION.md) for dependencies, later tickets and the no-self-review rule.

Use your own GitHub account. Read access is enough for setup; it does not establish write access. Never exchange credentials, upload employee data, or push to test permissions. If a lane is blocked, leave it intact and report the reason. For a test that cannot run, report **not run**, not passed.
