# Model seats and the employee runtime

| Side | Active seat | Role |
|---|---|---|
| Owner | Astra | Main coordinator; shared contracts and integration |
| Owner | Gemini Neon High | Isolation, then embedded inference |
| Friend | Sol 6.2 medium | Employee experience, then release qualification |
| Friend | Neon | Consent, recording and editable skills |

These are assignment labels, not evidence of a running model, a model ID, a benchmark result or GitHub permission. Distinguish the two Neon seats by side. Use only the assigned seat; if an existing session does not show its setting, say **unverified**. Do not change a selector, launch a runtime or send a test message to establish identity. See the [ticket and independent reviewer map](COORDINATION.md).

The proposed **employee** runtime is embedded, local [Gemma E2B](https://ai.google.dev/gemma/docs/capabilities/vision/image), not a developer seat. Before making support claims, verify the chosen weight format, license, memory use and accuracy on the target hardware. Structured observations are the default; the [vision review](docs/reviews/perception.md) covers the optional image path. Neither development accounts nor hosted services ship with the product.
