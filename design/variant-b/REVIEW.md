# Run ledger — reference review

Open `index.html` directly. It is the editable source: CSS variables set the palette and type, `steps` defines the sample manuscript, and `advance` drives playback. Reload restores the fixture.

For each incoming reference, record **reference / observed detail / keep, adapt or reject / reason**.

- At a glance, point to the current step, next decision and Stop. Does the reference make any easier to find?
- Compare the reading order, ruled rows and margin notes at the same desktop width. Which relationships survive without color?
- Record a sample, edit the wait and replay. Can the reviewer distinguish captured, planned, current and completed work?
- At clarification, verify neither tray is preselected. Can a keyboard user select, confirm or stop without losing their place?
- Withhold acknowledgment, stop during a wait and wait past its deadline. Is blocked work unmistakable without claiming the executor has stopped?
